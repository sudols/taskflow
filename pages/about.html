About TaskFlow

TaskFlow is a task management app built with latest web technologies.

Features

  • Task creation and management
  • Category based organization
  • Simple and efficient design
  • Fully offline capability

Technology Stack

Built with

  • HTML5
  • CSS3
  • JavaScript
  • Tailwind CSS
  • Webpack
Fully deployed and working on github pages.
